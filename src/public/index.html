    What's New in v0.4

    🧠 Smarter Suppression

    Context-aware false positive reduction. Documentation examples, placeholders, and tutorials no longer trigger false alarms.

    📊 Report Pages

    Every scan gets a shareable HTML report with dark theme, collapsible findings, and color-coded severity.

    ⚡ URL Caching

    5-minute cache for fetched URLs. Faster rescans, less load on skill hosts.

    🔗 Full CORS

    All endpoints support CORS. Browser-based agents can use the API directly.

    📦 Batch Scanning

    Scan up to 20 skill URLs in one request. Audit entire registries.

    🔄 Version Compare

    Diff two versions. See new findings, resolved issues, and risk delta.

    API Endpoints

    MethodEndpointDescription
    POST/scan/urlScan by URL (+ optional callback)
    POST/scan/contentScan raw content
    POST/scan/batchBatch scan (up to 20 URLs)
    POST/scan/compareCompare two skill versions
    GET/scan/:idGet scan result (JSON)
    GET/report/:idView scan report (HTML)
    GET/rulesList detection rules
    GET/historyRecent scan history
    GET/statsScan statistics
    POST/badge/requestRequest trust badge
    GET/badge/:domainCheck domain badge
    GET/openapi.jsonOpenAPI 3.0 spec

    Quick Start

    curl -X POST https://skillaudit.vercel.app/scan/url \
  -H "Content-Type: application/json" \
  -d '{"url": "https://example.com/SKILL.md"}'
