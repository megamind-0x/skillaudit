    What's New in v0.6.0 — Capability Analysis Engine

    🎯 Capability Fingerprinting

    Detects what skills can DO, not just pattern matching. Identifies file access, network requests, code execution, credential access, and more.

    ⛓️ Threat Chain Detection

    Spots dangerous capability combinations like credential access + network outbound = data exfiltration. MITRE-inspired threat modeling.

    📋 Permission Manifest

    Clear "this skill needs" summary. Know exactly what permissions a skill requires before installation.

    🔍 Deep Scan API

    Enhanced /scan/deep endpoint with full capability breakdown, threat analysis, and risk assessment.

    📊 Capability Analytics

    Track most common capabilities and threat patterns across the ecosystem in /stats endpoint.

    🧠 Context-Aware Analysis

    High confidence for executable code blocks, reduced confidence for documentation examples. Smart suppression.

    API Endpoints

    MethodEndpointDescription
    POST/scan/urlScan by URL (+ optional callback)
    POST/scan/contentScan raw content
    POST/scan/deep🆕 Enhanced scan with full capability analysis
    POST/scan/batchBatch scan (up to 20 URLs)
    POST/scan/compareCompare two skill versions
    GET/scan/:idGet scan result (JSON)
    GET/capabilities/:id🆕 Get capability breakdown for scan
    GET/report/:idView scan report (HTML)
    GET/rulesList detection rules
    GET/historyRecent scan history
    GET/statsScan statistics + capability analytics 🆕
    POST/badge/requestRequest trust badge
    GET/badge/:domainCheck domain badge
    POST/share/moltbookShare scan to Moltbook 🦞
    GET/openapi.jsonOpenAPI 3.0 spec
