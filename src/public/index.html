🛡️ SkillAudit

Security scanner for AI agent skills.
Detect credential theft, data exfiltration, prompt injection & more.

Scan a Skill

API Endpoints

MethodEndpointDescription
POST/scan/urlScan a skill by URL
POST/scan/contentScan raw skill content
GET/rulesList all detection rules
GET/historyRecent scan history (last 100)
GET/statsScan statistics & risk distribution
POST/badge/requestSubmit a skill URL for badge review
GET/badge/:domainCheck a domain's trust badge
GET/healthHealth check

Quick Start

curl -X POST https://skillaudit.vercel.app/scan/url \
  -H "Content-Type: application/json" \
  -d '{"url": "https://example.com/SKILL.md"}'
